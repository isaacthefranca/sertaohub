BARBERSAAS V7 — PRODUCTION CANDIDATE

- Docker de produção instala driver PostgreSQL e cliente pg_dump/psql.
- Ambiente staging separado.
- /health para liveness e /ready para banco.
- Cookies Secure em staging/produção.
- Trusted Hosts e headers básicos de segurança.
- Conta demo não é criada em staging/produção.
- APP_SECRET inseguro bloqueia inicialização em staging/produção.

- Script de restauração protegido por confirmação explícita.
- GitHub Actions para CI, staging automático e produção com aprovação manual.
